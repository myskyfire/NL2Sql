# 查询模板使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

查询模板用于管理和复用常用查询模板，提升查询效率。

## 🎯 核心功能

### 1. 模板管理
- 创建新模板
- 编辑模板内容
- 删除模板
- 模板分类

### 2. 模板使用
- 选择模板
- 填写参数
- 执行查询
- 保存结果

### 3. 模板分享
- 导出模板
- 导入模板
- 分享给其他用户

## 🔧 创建模板

### 步骤1：点击"新建模板"
在查询模板页面点击"新建模板"按钮。

### 步骤2：填写模板信息
| 字段 | 说明 | 示例 |
|------|------|------|
| 模板名称 | 模板名称 | 月度销售统计 |
| 模板描述 | 模板说明 | 统计每月销售额和订单量 |
| SQL 内容 | SQL 语句 | SELECT DATE_FORMAT(create_time, '%Y-%m') as month, COUNT(*) as order_count, SUM(amount) as total_amount FROM orders GROUP BY month ORDER BY month DESC |
| 分类 | 模板分类 | 销售分析 |

### 步骤3：保存
点击"保存"，模板创建成功。

## 💡 使用技巧

### 1. 参数化模板
使用变量代替固定值：
```sql
SELECT * FROM orders WHERE create_time >= '${start_date}' AND create_time <= '${end_date}'
```

### 2. 模板分类
- 按业务模块分类
- 按查询类型分类
- 按使用频率分类

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限才能创建模板
2. **权限校验**：执行模板时仍会进行权限校验
3. **模板维护**：定期清理不再使用的模板
