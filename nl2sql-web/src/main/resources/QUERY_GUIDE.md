# DataMind 查询使用指南

**最后更新**: 2026-05-31  
**适用版本**: DataMind AI v2.0+

## 📖 功能概述

DataMind 查询是系统的标准查询模式，用中文直接提问，AI 自动生成 SQL 并执行，支持多轮对话和上下文理解。

## 🎯 核心特性

### 1. 自然语言查询
- 使用中文直接提问
- 无需编写 SQL 语句
- 支持复杂查询逻辑

### 2. 多轮对话
- 支持上下文理解
- 可基于历史对话追问
- 自动继承查询条件

### 3. 结果展示
- 表格形式展示数据
- 支持排序和筛选
- 可导出查询结果

## 💡 使用示例

### 示例1：简单查询
```
问题：查询所有用户信息
SQL：SELECT * FROM users
```

### 示例2：条件查询
```
问题：查询2024年销售额大于10000的订单
SQL：SELECT * FROM orders WHERE YEAR(create_time) = 2024 AND amount > 10000
```

### 示例3：聚合查询
```
问题：统计每个地区的订单数量
SQL：SELECT region, COUNT(*) as order_count FROM orders GROUP BY region
```

## 🔧 查询技巧

### 1. 时间表达
- "最近7天"、"本月"、"今年"
- "2024年1月1日到2024年12月31日"
- "上周"、"上个月"、"去年"

### 2. 排序表达
- "按销售额降序"
- "按时间倒序"
- "按名称字母顺序"

### 3. 限制结果
- "前10条记录"
- "显示前5个"
- "TOP 10"

## ⚠️ 注意事项

1. **权限限制**：只能查询有权限的表
2. **结果限制**：默认最多返回1000条记录
3. **超时限制**：查询超时时间为30秒
4. **敏感数据**：自动过滤敏感字段

## 🐛 常见问题

### Q1: 查询结果为空？
A: 
1. 检查查询条件是否正确
2. 确认表中有数据
3. 尝试简化查询条件

### Q2: SQL 生成不准确？
A: 
1. 使用更明确的表述
2. 提供表名和字段名
3. 在 RAG 知识库中添加示例

### Q3: 如何导出结果？
A: 查询完成后，点击"导出"按钮，支持 CSV、Excel 格式。
