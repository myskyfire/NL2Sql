# 监控Dashboard使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

监控Dashboard用于查看系统运行状态，包括归一化效果、缓存命中率和 RAG 使用情况。

## 🎯 监控指标

### 1. 系统概览
| 指标 | 说明 |
|------|------|
| 总查询次数 | 系统累计查询次数 |
| 活跃用户数 | 今日活跃用户数 |
| 平均响应时间 | 平均查询响应时间 |
| 系统运行时间 | 系统连续运行时间 |

### 2. 缓存统计
| 指标 | 说明 |
|------|------|
| 缓存命中率 | 缓存命中次数/总查询次数 |
| 缓存大小 | 当前缓存占用空间 |
| 缓存条目数 | 缓存中的条目数量 |

### 3. RAG 使用统计
| 指标 | 说明 |
|------|------|
| RAG 检索次数 | 使用 RAG 检索的次数 |
| RAG 命中率 | RAG 成功匹配的次数 |
| QA 对数量 | 知识库中的 QA 对总数 |

### 4. 查询分析
- 查询类型分布
- 查询时间分布
- 热门表排名
- 热门字段排名

## 💡 使用示例

### 查看今日数据
1. 选择日期范围为今天
2. 查看各项指标
3. 分析趋势变化

### 导出报告
1. 点击"导出报告"
2. 选择导出格式
3. 下载报告文件

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **数据延迟**：统计数据可能有5分钟延迟
3. **刷新频率**：建议每5分钟刷新一次
