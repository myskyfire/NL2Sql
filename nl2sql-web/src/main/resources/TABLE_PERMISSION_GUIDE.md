# 表授权管理使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

表授权管理用于管理用户对数据库表的访问权限，支持按用户和按表双向查询。

## 🎯 核心功能

### 1. 按用户授权
- 选择用户
- 勾选允许访问的表
- 保存授权配置

### 2. 按表授权
- 选择数据表
- 添加允许访问的用户
- 保存授权配置

### 3. 权限查询
- 查看用户可访问的表
- 查看表的可访问用户
- 权限审计报告

## 🔧 授权操作

### 给用户授权
1. 选择目标用户
2. 在表列表中勾选允许访问的表
3. 点击"保存授权"

### 给表添加用户
1. 选择目标表
2. 在用户列表中选择要授权的用户
3. 点击"添加授权"

### 撤销权限
1. 找到目标授权记录
2. 点击"撤销"按钮
3. 确认撤销操作

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **权限继承**：管理员默认拥有所有表的权限
3. **权限生效**：权限变更后立即生效

## 🐛 常见问题

### Q1: 用户反馈看不到数据？
A: 检查该用户是否有对应表的访问权限。

### Q2: 如何批量授权？
A: 在授权页面，可以勾选多个表或用户进行批量操作。
