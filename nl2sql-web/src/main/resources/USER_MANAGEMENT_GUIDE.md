# 用户管理使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

用户管理用于创建和管理系统用户，分配角色和权限。

## 🎯 核心功能

### 1. 用户管理
- 创建新用户
- 编辑用户信息
- 禁用/启用用户
- 重置密码

### 2. 角色管理
| 角色 | 权限说明 |
|------|---------|
| admin | 管理员，拥有所有权限 |
| user | 普通用户，只能查询有权限的表 |

### 3. 权限分配
- 数据源权限
- 表级权限
- 功能权限

## 🔧 创建用户

### 步骤1：点击"添加用户"
在用户管理页面点击"添加用户"按钮。

### 步骤2：填写用户信息
| 字段 | 说明 | 示例 |
|------|------|------|
| 用户名 | 登录账号 | zhangsan |
| 姓名 | 真实姓名 | 张三 |
| 邮箱 | 联系邮箱 | zhangsan@example.com |
| 角色 | 用户角色 | user |
| 初始密码 | 登录密码 | ******** |

### 步骤3：保存
点击"保存"，用户创建成功。

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **密码安全**：建议使用强密码
3. **账号安全**：定期审查用户权限
