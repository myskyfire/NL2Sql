# 表关联管理使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

表关联管理用于配置和管理数据库表之间的关联关系，提升 SQL 生成的准确性。

## 🎯 为什么需要配置表关联？

AI 在生成 SQL 时，需要知道表之间的关联关系。如果没有配置关联，AI 可能：
- 无法正确生成 JOIN 语句
- 使用错误的关联字段
- 生成性能较差的查询

## 🔧 添加表关联

### 步骤1：选择主表和关联表
- 主表：查询的起点表
- 关联表：需要关联的目标表

### 步骤2：配置关联字段
| 字段 | 说明 | 示例 |
|------|------|------|
| 主表字段 | 主表的关联字段 | user_id |
| 关联表字段 | 目标表的关联字段 | id |
| 关联类型 | JOIN 类型 | INNER JOIN |

### 步骤3：保存配置
点击"保存"，关联关系立即生效。

## 📋 关联类型说明

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| INNER JOIN | 内连接，只返回匹配的行 | 两个表都有对应数据 |
| LEFT JOIN | 左连接，返回左表所有行 | 主表数据必须返回 |
| RIGHT JOIN | 右连接，返回右表所有行 | 关联表数据必须返回 |

## 💡 配置示例

### 示例1：用户和订单
```
主表：orders
关联表：users
主表字段：user_id
关联表字段：id
关联类型：INNER JOIN
```

### 示例2：订单和商品
```
主表：order_items
关联表：products
主表字段：product_id
关联表字段：id
关联类型：LEFT JOIN
```

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **字段类型**：关联字段类型应该一致
3. **索引建议**：关联字段建议创建索引
4. **循环关联**：避免配置循环关联

## 🐛 常见问题

### Q1: 关联后查询仍然不准确？
A: 
1. 检查关联字段是否正确
2. 确认关联类型是否合适
3. 在 RAG 知识库中添加示例

### Q2: 可以配置多表关联吗？
A: 可以，系统支持多表链式关联。

### Q3: 如何删除关联？
A: 找到目标关联关系，点击"删除"按钮。
