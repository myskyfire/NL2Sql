# 数据源管理使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

数据源管理用于配置和管理数据库连接，支持多种数据库类型，同步元数据到本地库。

## 🎯 支持的数据源类型

| 数据库类型 | 版本要求 | 说明 |
|-----------|---------|------|
| MySQL | 5.7+ | 完全支持 |
| PostgreSQL | 12+ | 完全支持 |
| Oracle | 11g+ | 基础支持 |
| SQL Server | 2017+ | 基础支持 |

## 🔧 添加数据源

### 步骤1：点击"添加数据源"
在数据源管理页面，点击"添加数据源"按钮。

### 步骤2：填写连接信息
| 字段 | 说明 | 示例 |
|------|------|------|
| 数据源名称 | 自定义名称 | 生产数据库 |
| 数据库类型 | 选择数据库类型 | MySQL |
| 主机地址 | 数据库服务器IP | 192.168.1.100 |
| 端口 | 数据库端口 | 3306 |
| 数据库名 | 目标数据库 | mydb |
| 用户名 | 数据库用户 | root |
| 密码 | 数据库密码 | ******** |

### 步骤3：测试连接
点击"测试连接"按钮，确认连接成功。

### 步骤4：保存并同步
点击"保存"，系统自动同步元数据。

## 📋 管理数据源

### 编辑数据源
1. 找到目标数据源
2. 点击"编辑"按钮
3. 修改连接信息
4. 保存并重新测试连接

### 删除数据源
1. 找到目标数据源
2. 点击"删除"按钮
3. 确认删除操作

### 同步元数据
1. 找到目标数据源
2. 点击"同步"按钮
3. 等待同步完成

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **网络安全**：建议使用只读账户
3. **连接池**：系统自动管理连接池
4. **元数据同步**：首次同步可能需要较长时间

## 🐛 常见问题

### Q1: 连接测试失败？
A: 
1. 检查主机地址和端口是否正确
2. 确认数据库服务已启动
3. 检查防火墙设置
4. 验证用户名和密码

### Q2: 元数据同步失败？
A: 
1. 确认数据库用户有读取元数据的权限
2. 检查数据库版本是否支持
3. 查看系统日志获取详细错误信息

### Q3: 如何批量导入数据源？
A: 暂不支持批量导入，需要逐个添加。
