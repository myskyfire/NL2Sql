# AI Agent 对话使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

AI Agent 对话是 DataMind AI 的核心功能，基于 ReAct（Reasoning + Acting）架构，支持多轮对话、自动追问、图表推荐和数据分析。

## 🎯 核心特性

### 1. 多轮对话支持
- 系统会自动保存对话上下文
- 支持基于历史对话的连续追问
- 上下文窗口可配置（默认10轮）

### 2. 自动追问
- 当查询结果不完整时，Agent 会自动追问
- 支持澄清用户意图
- 提供选项供用户快速选择

### 3. 图表推荐
- 根据查询结果自动推荐合适的图表类型
- 支持柱状图、折线图、饼图、散点图等
- 可一键切换图表类型

### 4. 数据分析
- 自动识别数据趋势和异常值
- 提供关键指标摘要
- 生成数据洞察报告

## 💡 使用示例

### 示例1：基础查询
```
用户：查询最近30天的订单数量
Agent：生成SQL并执行，返回结果和图表
```

### 示例2：多轮对话
```
用户：查询最近30天的订单数量
Agent：返回结果

用户：按地区分组呢？
Agent：基于上下文，重新生成按地区分组的SQL
```

### 示例3：数据分析
```
用户：分析本月销售趋势
Agent：返回趋势图，并提供关键洞察：
- 销售额环比增长15%
- 周末销售额明显高于工作日
- 建议关注周三的低谷期
```

## 🔧 高级功能

### 1. 自定义分析维度
```
用户：按产品类别和地区分析销售额
Agent：生成多维分析SQL，返回交叉表
```

### 2. 时间序列分析
```
用户：对比今年和去年同期的销售数据
Agent：生成同比分析SQL，返回对比图表
```

### 3. 异常检测
```
用户：找出销售额异常的订单
Agent：使用统计方法识别异常值，返回分析报告
```

## ⚠️ 注意事项

1. **权限限制**：只能查询有权限的数据库表
2. **查询复杂度**：过于复杂的查询可能需要多轮对话澄清
3. **性能优化**：大数据量查询会自动添加LIMIT限制
4. **上下文管理**：对话历史会占用内存，建议定期开启新对话

## 🐛 常见问题

### Q1: Agent 不理解我的问题怎么办？
A: 尝试使用更明确的表述，包含具体的表名、字段名或时间范围。

### Q2: 如何清除对话历史？
A: 点击页面右上角的"新对话"按钮即可清除上下文。

### Q3: 查询结果不准确怎么办？
A: 
1. 检查问题描述是否清晰
2. 提供更多上下文信息
3. 使用"表关联管理"配置表关系
4. 在"RAG知识库"中添加示例QA对

### Q4: 图表显示不正常？
A: 
1. 检查浏览器是否支持Canvas
2. 尝试刷新页面
3. 确认查询结果包含数值数据

## 📊 性能指标

- **响应时间**：简单查询 < 3秒，复杂查询 < 10秒
- **准确率**：标准查询 > 90%，复杂查询 > 75%
- **上下文窗口**：默认10轮对话
