## 技术细节

1. **路由策略**
   - 高置信度(>=0.8) → DIRECT直接调用
   - 中等置信度(0.5-0.8) → LLM_ASSISTED辅助决策
   - 低置信度(<0.5) → FALLBACK降级到完整ReAct

2. **工具可见性**
   - PUBLIC: 对LLM可见（高层Skills）
   - INTERNAL: 对LLM不可见（原子Tools）
   - ToolDefinitionConverter默认过滤INTERNAL tools

3. **监控指标**
   - 使用AOP自动拦截com.nl2sql.core.agent.skills..*.execute()
   - 记录totalCalls、successRate、averageExecutionTimeMs等
   - 提供GET /api/admin/skill-metrics查询接口

4. **统一上下文**
   - AgentContext贯穿整个执行流程
   - 提供metadata扩展机制
   - 替代分散的SessionContext/SkillContext
