# 流式对话使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

流式对话功能基于 SSE（Server-Sent Events）技术，实时展示 SQL 生成过程，让用户能够看到 AI 的思考步骤和 SQL 构建过程。

## 🎯 核心特性

### 1. 实时流式输出
- SQL 生成过程逐字显示
- 思考步骤实时可见
- 无需等待完整响应

### 2. 多步骤展示
- **意图理解**：分析用户查询意图
- **表选择**：识别需要查询的表
- **字段映射**：匹配用户提到的字段
- **SQL 构建**：逐步生成 SQL 语句
- **执行结果**：显示查询结果

### 3. 过程可中断
- 发现错误可立即停止
- 节省服务器资源
- 快速重新提问

## 💡 使用示例

### 示例1：查看SQL生成过程
```
用户输入：查询最近30天的订单

流式输出：
[思考] 用户想查询订单数据...
[思考] 需要查询 orders 表...
[思考] 时间范围是最近30天...
[SQL] SELECT * FROM orders WHERE create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
[执行] 查询成功，返回 1,234 条记录
```

### 示例2：复杂查询
```
用户输入：按地区统计本月销售额

流式输出：
[思考] 需要统计销售额...
[思考] 涉及 orders 和 users 表...
[思考] 需要关联两个表...
[思考] 按地区分组并求和...
[SQL] SELECT u.region, SUM(o.amount) FROM orders o JOIN users u ON o.user_id = u.id WHERE o.create_time >= DATE_FORMAT(NOW(), '%Y-%m-01') GROUP BY u.region
[执行] 查询成功，返回 15 个地区的数据
```

## 🔧 技术细节

### SSE 连接
- 使用 EventSource API
- 自动重连机制
- 连接超时：60秒

### 消息类型
| 消息类型 | 说明 | 示例 |
|---------|------|------|
| thinking | 思考过程 | "正在分析查询意图..." |
| sql | SQL片段 | "SELECT * FROM orders" |
| result | 执行结果 | "返回 100 条记录" |
| error | 错误信息 | "表不存在" |
| done | 完成信号 | 流式输出结束 |

## ⚠️ 注意事项

1. **浏览器支持**：需要现代浏览器（Chrome 6+, Firefox 6+, Safari 5+）
2. **网络要求**：保持网络连接稳定
3. **超时处理**：复杂查询可能超时，建议简化问题
4. **中断操作**：点击"停止"按钮可中断当前查询

## 🐛 常见问题

### Q1: 流式输出卡住不动？
A: 
1. 检查网络连接
2. 点击"停止"按钮重新开始
3. 尝试简化查询问题

### Q2: 显示乱码？
A: 
1. 检查浏览器编码设置（应为 UTF-8）
2. 刷新页面重试

### Q3: 连接频繁断开？
A: 
1. 检查防火墙设置
2. 确认代理服务器支持 SSE
3. 尝试直接连接（不使用代理）

### Q4: 如何查看完整SQL？
A: 流式输出完成后，SQL 语句会显示在结果区域，可点击"复制"按钮复制完整 SQL。

## 📊 性能指标

- **首字延迟**：< 500ms
- **输出速度**：约 50-100 字/秒
- **连接超时**：60秒
- **自动重连**：最多3次
