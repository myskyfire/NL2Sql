# 执行日志使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

执行日志用于查看所有 SQL 执行记录，包括执行时间、性能分析和慢查询监控。

## 🎯 核心功能

### 1. 日志查询
- 按时间范围查询
- 按用户查询
- 按表名查询
- 按执行状态查询

### 2. 性能分析
| 指标 | 说明 |
|------|------|
| 执行时间 | SQL 执行耗时 |
| 扫描行数 | 扫描的数据行数 |
| 返回行数 | 返回的结果行数 |
| 执行状态 | 成功/失败 |

### 3. 慢查询监控
- 设置慢查询阈值
- 自动标记慢查询
- 慢查询分析报告

## 💡 使用示例

### 查询今日执行记录
1. 选择日期范围为今天
2. 点击"查询"
3. 查看执行记录列表

### 分析慢查询
1. 设置执行时间阈值（如 > 5秒）
2. 筛选慢查询记录
3. 分析 SQL 语句

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **日志保留**：日志默认保留30天
3. **性能影响**：大量日志可能影响查询速度
