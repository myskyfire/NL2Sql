# RAG知识库使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

RAG（Retrieval-Augmented Generation）知识库用于导入和管理 QA 对，通过示例优化 SQL 生成质量，支持批量导入和智能检索。

## 🎯 核心特性

### 1. QA对管理
- 添加自然语言问题和对应 SQL
- 编辑和删除现有 QA 对
- 批量导入导出

### 2. 智能检索
- 基于语义相似度检索
- 自动匹配最相关的示例
- 提升 SQL 生成准确率

### 3. 分类管理
- 按业务场景分类
- 按表名分类
- 按难度分级

## 🔧 添加 QA 对

### 步骤1：点击"添加 QA"
在知识库页面点击"添加 QA"按钮。

### 步骤2：填写信息
| 字段 | 说明 | 示例 |
|------|------|------|
| 问题 | 自然语言问题 | 查询最近30天的订单 |
| SQL | 对应的 SQL 语句 | SELECT * FROM orders WHERE create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY) |
| 分类 | 业务分类 | 订单查询 |
| 标签 | 关键词标签 | 订单,时间范围 |
| 优先级 | 匹配优先级 | 高/中/低 |

### 步骤3：保存
点击"保存"，QA 对立即生效。

## 📋 批量导入

### 支持格式
- CSV 文件
- Excel 文件
- JSON 文件

### 导入模板
```csv
问题,SQL,分类,标签,优先级
查询最近30天的订单,SELECT * FROM orders WHERE...,订单查询,订单,高
```

## 💡 使用技巧

### 1. 高质量 QA 对
- 问题描述清晰明确
- SQL 语句经过验证
- 覆盖常见查询场景

### 2. 分类策略
- 按业务模块分类
- 按表名分类
- 按查询类型分类

### 3. 标签使用
- 使用关键词作为标签
- 便于搜索和筛选
- 建议3-5个标签

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **QA质量**：确保 SQL 语句正确可执行
3. **数量建议**：每个业务场景至少10个 QA 对
4. **定期更新**：根据使用情况持续优化

## 🐛 常见问题

### Q1: 导入失败？
A: 
1. 检查文件格式是否正确
2. 确认字段映射正确
3. 查看错误日志

### Q2: 检索不准确？
A: 
1. 增加更多 QA 对
2. 优化问题描述
3. 调整分类和标签

### Q3: 如何导出 QA 对？
A: 点击"导出"按钮，选择导出格式。
