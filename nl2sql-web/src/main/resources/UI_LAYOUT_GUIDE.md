#### 数据表格
```
位置: 第382-397行

┌────┬────┬──────────┬──────┬────────────┬────────┬──────┬──────┬──────────┬────────┐
│ ☑  │ ID │ 概念键    │ 类型  │ 别名        │ 描述    │ 使用  │ 状态  │ 创建时间  │ 操作    │
├────┼────┼──────────┼──────┼────────────┼────────┼──────┼──────┼──────────┼────────┤
│ ☑  │ 1  │ revenue  │[指标]│销售额,收入  │销售总金..│ 125  │[已通过]│2026-04-20│编辑 删除│
│    │ 2  │ profit   │[指标]│利润,净利润  │销售收入..│  89  │[已通过]│2026-04-20│编辑 删除│
│ ☑  │ 3  │ gmv_new  │[指标]│GMV,流水    │待审核概念│   0  │[待审核]│2026-04-20│通过 拒绝│
│    │    │          │      │            │        │      │      │          │编辑 删除│
└────┴────┴──────────┴──────┴────────────┴────────┴──────┴──────┴──────────┴────────┘

列说明:
1. 复选框: 仅"待审核"状态可勾选
2. ID: 数据库主键
3. 概念键: 英文标识（加粗显示）
4. 类型: 彩色徽章（蓝色=实体, 绿色=指标, 橙色=维度）
5. 别名: 逗号分隔的中文同义词
6. 描述: 截断显示50字符，悬停看全文
7. 使用次数: 被NL2SQL引用的次数
8. 状态: 彩色徽章（绿色=已通过, 黄色=待审核, 红色=已拒绝）
9. 创建时间: 格式化日期时间
10. 操作: 
    - 待审核: [通过] [拒绝] [编辑] [删除]
    - 已审核: [编辑] [删除]
```

## 🎯 交互流程图

### 批量导入流程
```
用户点击"📥 批量导入"
        ↓
  显示导入模态框
        ↓
  选择行业 + 上传文件
        ↓
  点击"👁️ 预览"
        ↓
  FileReader读取CSV
        ↓
  parseCSV()解析内容
        ↓
  显示预览表格（前5条）
        ↓
  用户确认数据正确
        ↓
  点击"✅ 开始导入"
        ↓
  循环遍历importData数组
        ↓
  逐条调用POST API
        ↓
  统计成功/跳过/失败数量
        ↓
  显示结果对话框
        ↓
  关闭模态框 + 刷新列表
```

### 批量审核流程
```
用户勾选多个待审核概念
        ↓
  updateBatchActions()触发
        ↓
  显示批量操作栏
        ↓
  更新已选择数量
        ↓
用户点击"✅ 批量通过"
        ↓
  收集所有选中项的ID
        ↓
  弹出确认对话框
        ↓
  用户确认
        ↓
  调用POST /batch-approve
        ↓
  请求体: {ids: [1,2,3], action: "approve"}
        ↓
  后端执行UPDATE语句
        ↓
  返回成功消息
        ↓
  前端显示提示
        ↓
  取消全选 + 隐藏操作栏
        ↓
  刷新列表（状态已更新）
```
