# 元数据查看使用指南

**最后更新**: 2026-05-04  
**适用版本**: DataMind AI v1.4.0+

## 📖 功能概述

元数据查看用于浏览数据库表结构、字段信息、索引详情等元数据信息。

## 🎯 核心功能

### 1. 表结构查看
- 查看所有数据表
- 表基本信息（行数、大小、创建时间）
- 表注释和描述

### 2. 字段信息
- 字段名称和类型
- 字段长度和精度
- 是否允许为空
- 默认值
- 字段注释

### 3. 索引信息
- 索引名称
- 索引类型（主键、唯一、普通）
- 索引字段
- 索引状态

## 💡 使用示例

### 查看表结构
1. 在表列表中选择目标表
2. 查看表的基本信息
3. 切换到"字段"标签查看字段详情

### 查看索引
1. 选择目标表
2. 切换到"索引"标签
3. 查看所有索引信息

## ⚠️ 注意事项

1. **权限要求**：需要管理员权限
2. **数据同步**：元数据需要定期同步
3. **性能影响**：查看大表元数据可能较慢

## 🐛 常见问题

### Q1: 元数据不更新？
A: 点击"同步"按钮手动同步元数据。

### Q2: 看不到某些表？
A: 确认数据库用户有访问这些表的权限。
